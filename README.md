# Jira Agents

Плагин Kimi Code CLI для получения задач Jira и делегирования их реализации отдельному агенту.

В комплект входят:

- `jira-reader` — получает список активных задач или полный контекст выбранной задачи;
- `jira-implementer` — реализует задачу в текущем проекте и проверяет результат;
- навык `jira-tasks` — координирует работу агентов;
- MCP-сервер `jira` с инструментами `list_active_issues` и `get_issue`.

MCP-сервер использует только стандартную библиотеку Python. Устанавливать Python-пакеты не требуется.

## Обоснование проекта

Проект автоматизирует рабочий процесс **end to end**: от получения задачи из Jira до реализации и проверки изменений в проекте. Он устраняет ручной перенос требований между Jira и средой разработки, снижает риск потери контекста и делает проверку результата частью единого процесса.

Рабочий цикл выглядит так:

1. **Получение задач.** Пользователь запрашивает назначенные ему задачи, не переключаясь между Jira и редактором.
2. **Выбор и подготовка контекста.** После выбора задачи `jira-reader` собирает описание, критерии приёмки, комментарии, связи, подзадачи и метаданные вложений.
3. **Реализация.** Координатор передаёт полный контекст `jira-implementer`, который изучает кодовую базу и вносит изменения в соответствии с соглашениями проекта.
4. **Проверка.** Агент запускает стандартные сборку и тесты проекта, а также по возможности воспроизводит исходный сценарий задачи.
5. **Передача результата.** Пользователь получает сводку изменений, список затронутых файлов, результаты проверок и сведения об оставшихся ограничениях.

Таким образом, Jira остаётся источником требований, а Kimi Code связывает их с реализацией и проверкой. Пользователь сохраняет контроль над процессом: без отдельного запроса агенты не создают коммиты, не отправляют изменения в удалённый репозиторий и не меняют статус задачи в Jira.

## Требования

- Kimi Code CLI с поддержкой плагинов;
- Python, доступный командой `python`;
- персональный токен Jira с правом чтения задач.

## Настройка Jira

Сохраните токен в отдельном файле без кавычек и дополнительного текста. Не добавляйте этот файл в репозиторий.

Перед запуском Kimi Code задайте переменные окружения:

```bash
export JIRA_BASE_URL="https://jira.example.com"
export JIRA_TOKEN_FILE="$HOME/.config/jira/token"
```

`JIRA_BASE_URL` — адрес Jira без завершающего `/`. `JIRA_TOKEN_FILE` — путь к файлу с токеном. Kimi Code наследует эти переменные и передаёт их MCP-серверу; в манифесте плагина секреты не хранятся.

## Установка

Из локального каталога:

```text
/plugins install /absolute/path/to/jira-agents
```

После публикации репозитория на GitHub:

```text
/plugins install https://github.com/<owner>/jira-agents
```

Затем выполните:

```text
/reload
```

Проверить состояние MCP-сервера можно командой `/mcp`, а диагностику плагина — `/plugins info jira-agents`.

Если сервер `jira` уже настроен вручную в `~/.kimi-code/mcp.json` или `.kimi-code/mcp.json`, отключите либо удалите старую запись, чтобы не запускать два экземпляра одного сервера. Переменные окружения из её секции `env` нужно перенести в окружение, из которого запускается Kimi Code.

Плагин устанавливается для пользователя и становится доступен во всех проектах. При локальной установке Kimi Code использует управляемую копию, поэтому после изменения исходников плагин нужно установить повторно.

## Использование

Запросите список задач:

```text
Дай задачи
```

Затем выберите задачу для реализации, например:

```text
Реализуй FAN-123
```

`jira-reader` только читает Jira и не получает доступ к учётным данным напрямую. `jira-implementer` не подключается к Jira: он получает контекст задачи от координатора, изменяет проект и запускает относящиеся к изменению проверки.

## Использование MCP-сервера отдельно

Сервер можно подключить к другому MCP-клиенту как stdio-процесс:

```bash
python /absolute/path/to/jira-agents/mcp/jira_mcp_server.py
```

Процессу нужны те же переменные `JIRA_BASE_URL` и `JIRA_TOKEN_FILE`.

## Обновление

Повторите команду `/plugins install` с каталогом, веткой, тегом или коммитом, после чего выполните `/reload`. Форматы ссылок и управление плагинами описаны в [официальной документации Kimi Code](https://moonshotai.github.io/kimi-code/en/customization/plugins).
